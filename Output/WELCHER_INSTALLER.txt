📋 INSTALLATIONS-SCHRITTE IM VERGLEICH
═══════════════════════════════════════════════════════════════════════

EINFACHER INSTALLER:
1. Python installieren (manuell)
2. Installer ausführen
3. PowerShell öffnen
4. cd C:\teleclinic-bot
5. pip install -r requirements.txt (manuell)
6. playwright install chromium (manuell)
7. Chrome Debug-Verknüpfung erstellen (manuell)
8. Lizenzcode eingeben
9. Bot starten
→ Ca. 10-15 Minuten, technisches Wissen nötig

FULL INSTALLER:
1. Python installieren (manuell, falls nicht vorhanden)
2. Installer ausführen → macht automatisch: pip, requirements, playwright
3. Chrome Debug Icon auf Desktop nutzen
4. Lizenzcode eingeben
5. Bot starten
→ Ca. 5-7 Minuten, KEIN technisches Wissen nötig
