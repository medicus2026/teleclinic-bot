```

```

```
Doppelklick: TeleClinic-Bot.exe
```

## ❓ HÄUFIGE FRAGEN

**Q: Muss ich auf jedem PC neu builden?**  
A: Nein! Einmal builden, dann ZIP auf alle PCs verteilen.

**Q: Funktioniert das ohne Internet?**  
A: Zum Installieren ja, zum Nutzen braucht Teleclinic Internet.

**Q: Kann ich das Passwort nachträglich ändern?**  
A: Ja, siehe BUILD_INSTALLATION_GUIDE.md Abschnitt "Passwort ändern".

**Q: Was passiert bei Windows Updates?**  
A: Programm funktioniert weiter. Bei Problemen: Neu entpacken.
