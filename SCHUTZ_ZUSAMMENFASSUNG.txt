WIE FUNKTIONIERT ES?

  1. Installation auf PC
     └─> Aktivierungs-Dialog erscheint

  2. Passwort eingeben: "Hanbo2001!"
     └─> Software erstellt Hardware-ID (einzigartig pro PC)

  3. Lizenz wird erstellt
     └─> Gebunden an: CPU + Motherboard + MAC-Adresse

  4. Bei jedem Start
     └─> Prüfe Hardware-ID
     └─> Stimmt? ✅ Starte Programm
     └─> Stimmt nicht? ❌ Aktivierung erforderlich

  5. Bei Weitergabe an anderen PC
     └─> Andere Hardware-ID
     └─> ❌ "Lizenz ist für einen anderen PC!"
     └─> Programm startet NICHT

  3. Fehler-Dialog

     │ Diese Software ist an einen anderen   │
     │ PC gebunden!                           │

     │ Kontaktieren Sie den Administrator    │
     │ für eine neue Lizenz.                  │
     └────────────────────────────────────────┘

  4. Programm startet NICHT
     └─> ✅ Schutz funktioniert!
